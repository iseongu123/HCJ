# 焼き Family MT (가평 1박 2일 팀 MT 페이지)

가평 1박 2일 팀 MT의 일정, 오시는 길, 먹거리, 레크리에이션, 준비물, 팀원, QR 정보를 한 페이지에 모은 안내 웹앱이에요. D-DAY 카운트다운과 타임테이블도 함께 보여줘요. `Code_2.gs`가 있는 걸 보면 Google Apps Script와 연동해서 팀원 정보 등을 관리하도록 만들었어요.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | MT 안내 페이지 UI |
| `Code_2.gs` | Google Apps Script 서버 로직 |
| `assets/qr.png` | 공유용 QR 코드 이미지 |

## 실행 방법

폴더 안의 `index.html`을 더블클릭하면 바로 실행돼요.
