# 🔮 나나도사, 오늘의 운세 (예제 23)

이름, 생일, 성별을 입력하고 불/물/나무/땅/바람 다섯 원소 중 하나를 고르면, 그에 어울리는 오늘의 운세를 랜덤으로 보여주는 운세 웹 앱이에요.

## 실행 결과

![실행 결과](screenshot.png)

"성준민"이라는 이름과 생일, 성별, "불" 원소를 선택하고 운세를 뽑은 결과 화면이에요. 이름을 넣어 개인화된 문구와 함께 오늘의 운세 카드가 표시돼요.

## 주요 기능

- 이름 / 생일 / 성별 입력 폼과 실시간 유효성 검사
- 불·물·나무·땅·바람 5원소 카드 선택 UI
- 원소별로 준비된 운세 문구 중 랜덤 출력
- "같은 정보로 다시 뽑기" / "처음부터 다시하기" 버튼

## 기술 스택

- Vanilla HTML/CSS/JavaScript
- 다크 톤의 별빛 테마 디자인

## 실행 방법

`index.html`을 더블클릭해서 브라우저로 열면 바로 사용할 수 있어요.
