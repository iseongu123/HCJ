# 💥 나만 아니면 돼! 복불복 캐논 추첨기 (예제 30)

여러 사람의 이름을 입력하고 대포를 발사하면, 구슬이 여러 장애물(핀)을 튕기며 떨어지다가 마지막에 도착한 칸의 사람이 당첨자가 되는 물리 시뮬레이션 추첨기예요.

## 실행 결과

![실행 결과](screenshot.png)

성준민, 김철수, 이영희, 박지훈 네 명의 이름을 넣고 대포를 발사한 결과, 구슬이 "이영희" 칸에 떨어져 당첨자로 뽑힌 화면이에요.

## 주요 기능

- 이름을 여러 명 추가하고 목록 관리
- "발사!" 버튼을 누르면 구슬이 핀(장애물)에 튕기며 떨어지는 물리 애니메이션
- 구슬이 멈추는 위치(칸)에 해당하는 사람이 자동으로 당첨자로 결정
- 당첨자 발표 팝업과 "다시 뽑기" 기능

## 기술 스택

- Vanilla HTML/CSS/JavaScript
- [Matter.js](https://brm.io/matter-js/) (`vendor/matter.min.js`) — 갈톤 보드(Galton board) 형태의 핀·칸 물리 연산
- Canvas 2D로 직접 렌더링

## 실행 방법

`index.html`을 더블클릭해서 브라우저로 열면 바로 사용할 수 있어요.

## 💬 소감

구슬이 핀에 튕기는 물리 시뮬레이션을 처음부터 직접 구현해보면서 낯설었던 물리 연산도 하나씩 이해하며 완성했어요. **내가 직접 해봤으니 다음에 비슷한 물리 시뮬레이션 앱이 필요할 때도 충분히 만들 수 있어요.**
