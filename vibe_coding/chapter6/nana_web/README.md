# ✍️ 글자 수 세기 (예제 24)

텍스트를 입력하면 글자 수, 공백 제외 글자 수, 단어 수, 바이트 수를 실시간으로 계산해주는 웹 앱이에요. 한글은 1글자당 2byte로 계산하는 규칙을 반영했어요.

## 실행 결과

![실행 결과](screenshot.png)

한글과 영어가 섞인 문장을 입력했을 때 글자 수(공백 포함/제외), 단어 수, 바이트 수가 실시간으로 계산되는 모습이에요.

## 주요 기능

- 입력창에 텍스트를 타이핑하는 즉시 통계 갱신
- 글자 수(공백 포함 / 공백 제외), 단어 수, 바이트 수 4종 통계
- 한글(및 기타 2byte 문자)은 2byte, 영문/숫자/기호는 1byte로 계산
- "지우기" 버튼으로 입력창 초기화

## 핵심 로직

```js
function getByteLength(str) {
  var byteLen = 0;
  for (var i = 0; i < str.length; i++) {
    var code = str.charCodeAt(i);
    byteLen += code > 127 ? 2 : 1;
  }
  return byteLen;
}
```
