# 스터디 시간 조율 (Google Apps Script 웹앱)

대학생 스터디 팀원들이 학번/이름을 입력하고 가능한 시간대를 체크해서 제출하면,
Google 스프레드시트에 자동으로 쌓이는 웹앱입니다. Google Apps Script(GAS)로 개발·배포하며
별도 서버나 호스팅 없이 구글 계정만으로 운영할 수 있습니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `code.gs` | 서버 로직 (스프레드시트 저장, 중복 학번 검증, 웹앱 진입점) |
| `index.html` | 입력 화면 UI (Tailwind CDN + Hanken Grotesk 폰트, 민트 그린 톤 디자인) |

## 스프레드시트 헤더 구조

`code.gs`의 `setupHeader()` 함수를 한 번 실행하면 아래 헤더가 1행에 자동 생성됩니다.

| 열 | 항목 | 설명 |
|---|---|---|
| A | 타임스탬프 | 제출 시각 자동 기록 |
| B | 회차 | `code.gs`의 `CURRENT_ROUND` 값 (예: `1주차`) |
| C | 학번 | 텍스트 서식 고정 (숫자로 변환되지 않도록 처리) |
| D | 이름 | |
| E | 가능한 시간대 | `"월 09:00~12:00, 수 15:00~18:00"` 형태로 콤마 구분 저장 |
| F | 비고 | 선택 입력 |
| G | 동아리 활동 내용 | 필수 입력 |

## 학번 중복 제출 방지

- **"학번 + 회차" 조합**으로 중복을 판단합니다. 같은 학번이라도 회차가 다르면 다시 제출할 수 있고,
  같은 회차 안에서는 한 번만 제출됩니다.
- 학생이 회차를 직접 입력하지 않도록 설계했습니다. 오타로 중복 검증이 무력화되는 것을 막기 위해
  회차 값은 관리자가 `code.gs`의 `CURRENT_ROUND` 상수로만 관리합니다.
- 입력 화면에서 학번을 4자 이상 입력하면 실시간으로 "제출 가능한 학번입니다 / 이미 제출한 학번입니다"
  안내가 뜨고(`checkStudentId`), 실제 제출 시에도 서버(`submitForm`)에서 한 번 더 검증합니다.
- `LockService`로 동시 제출로 인한 중복 저장도 방지합니다.

## 처음 설정하는 방법

1. Google 스프레드시트를 새로 만들거나 기존 시트를 준비합니다.
2. 스프레드시트에서 **확장 프로그램 → Apps Script**로 편집기를 엽니다.
3. `코드.gs`(또는 `Code.gs`)와 `index.html` 두 파일을 만들어 이 저장소의 내용을 각각 붙여넣습니다.
   (HTML 파일명은 반드시 `index`여야 `doGet()`이 찾을 수 있습니다.)
4. `code.gs` 상단의 값을 본인 환경에 맞게 수정합니다.
   - `SHEET_URL`: 사용할 스프레드시트 주소
   - `SHEET_NAME`: 데이터를 쌓을 시트 탭 이름 (없으면 첫 번째 시트 사용)
   - `CURRENT_ROUND`: 현재 회차 값 (예: `'1주차'`)
5. 함수 목록에서 `setupHeader`를 선택해 한 번 실행합니다. (최초 실행 시 권한 승인 팝업이 뜨면 허용)
   → 시트 1행에 헤더(A~G)가 자동 생성됩니다.
6. **배포 → 새 배포**를 클릭합니다.
   - 유형: **웹 앱**
   - 액세스 권한: **모든 사용자**
   - 실행: **나**
7. 배포 후 나오는 `.../exec` 형태의 URL이 실제 학생들이 접속할 주소입니다. 이 주소로 QR코드를 만들어 배포하세요.

## 새 회차(주차)를 시작할 때

1. `code.gs`의 `CURRENT_ROUND` 값만 다음 값으로 바꿉니다. (예: `'1주차'` → `'2주차'`)
2. **배포 → 배포 관리 → (연필 아이콘) → 버전: 새 버전 → 배포**로 재배포합니다.

> ⚠️ **주의:** "배포 → 새 배포"를 다시 누르면 URL이 새로 생성되어 기존에 만든 QR코드가 무효화됩니다.
> 코드나 회차를 수정할 때는 반드시 **"배포 관리 → 새 버전"** 경로로만 재배포해야 QR/URL이 유지됩니다.

## 화면 구성 커스터마이징

`index.html` 하단 `<script>`의 다음 배열만 수정하면 요일 범위와 시간 단위를 쉽게 바꿀 수 있습니다.

```js
var DAYS = ['월', '화', '수', '목', '금', '토', '일'];
var WEEKEND_DAYS = ['토', '일']; // 빨간색으로 강조 표시할 요일
var TIME_BLOCKS = ['09:00~12:00', '12:00~15:00', '15:00~18:00', '18:00~21:00', '21:00~24:00'];
```

하단의 "팀원에게 이 설문 공유하기" 박스에는 배포 URL을 단축한 QR 이미지와 링크가 삽입되어 있습니다.
링크가 바뀌면 `index.html`에서 `<img>`의 base64 QR 이미지와 `id="shareLink"` 앵커의 `href`/텍스트를 교체하면 됩니다.

## 주요 서버 함수 (`code.gs`)

| 함수 | 설명 |
|---|---|
| `doGet()` | 웹앱 접속 시 `index.html`을 렌더링하고 현재 회차 값을 화면에 전달 |
| `checkStudentId(studentId)` | 입력 중 실시간 중복 확인 |
| `submitForm(data)` | 최종 제출 처리, 중복/필수값 서버 검증 후 시트에 저장 |
| `setupHeader()` | 시트 1행에 헤더를 자동 생성 (최초 1회 실행용) |

## 문제 해결

- **제출은 되는데 시트에 안 쌓여요** → `SHEET_URL`이 정확한지, 스크립트를 실행하는 구글 계정이 해당
  스프레드시트에 접근 권한이 있는지 확인하세요.
- **학번이 숫자로 저장돼서 앞자리 0이 사라져요** → 이미 텍스트 서식(`setNumberFormat('@')`)을 자동 적용하지만,
  기존에 잘못 저장된 값이 있다면 C열을 선택해 서식을 "일반 텍스트"로 바꾼 뒤 값을 다시 입력해야 합니다.
- **재배포했는데 QR이 안 열려요** → "새 배포"가 아니라 "배포 관리 → 새 버전"으로 재배포했는지 확인하세요.
