# 성준민의 이력서

프로필 카드, ABOUT, CONTACT 섹션과 유튜브 영상 임베드까지 담은 온라인 이력서 페이지예요. `css/style.css`로 스타일을 분리하고, SNS 아이콘(블로그/이메일/페이스북/모바일)을 붙였어요.

## 실행 방법

폴더 안의 `index.html`을 더블클릭하면 바로 실행돼요. (`css/style.css`, `images/*`, `movie.mp4` 필요)
